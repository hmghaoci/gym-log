# 可切换 UI 风格设计

日期：2026-10-18  
仓库：gym-log  
状态：预览已获用户确认（余烬 / 薄雾 / 脉冲 / 锻火）

## 1. 目标

- 用户在首页可切换界面风格，立即生效，下次打开记住选择。
- 四套风格各有独立气质与配图，互不复用同一张图。
- 与另一会话的功能开发（备份 / 休息提醒 / 进步曲线）不冲突：本改动主改 CSS 与少量主题切换 JS。

## 2. 非目标（首版不做）

- 跟随系统自动切换（可后加 `system`）。
- 远程下载主题包。
- 改训练业务逻辑、模板、历史数据结构。
- 把预览里的「本周容量大数字 / 进度环」做成真实功能（那是视觉示意；真实数据仍用现有记录）。

## 3. 四套风格（已确认）

| 键名 | 名称 | 气质 | 配图前缀（仅本套使用） |
|------|------|------|------------------------|
| `ember` | 余烬 | 深底暖橙光晕、玻璃数字卡 | `ember-*` |
| `mist` | 薄雾 | 浅色磨砂卡片浮在训练照片上 | `mist-*` |
| `pulse` | 脉冲 | 黑底紫青光带、玻璃数据块 | `pulse-*` |
| `forge` | 锻火 | 哑光黑、橙边高光、大字动作卡 | `forge-*` |

默认：`ember`（或保留当前浅色为首次安装默认；实现时若需「首次仍是旧浅色」，可加 `day` 仅作默认，不进选择器——**实现默认采用 `ember`**，与预览一致）。

## 4. 存储与应用

- `localStorage` 键：`gymlog.theme`，值为上表键名。
- 启动时读取并设到 `document.documentElement`（或 `body`）的 `data-theme`。
- `meta theme-color` 随当前主题主背景色更新。
- 中英文：`界面风格` / `Look`，四套名称中英各一份短标签。

## 5. UI 入口

- 首页、语言切换附近增加「界面风格」横向芯片（可横滑）：余烬 / 薄雾 / 脉冲 / 锻火。
- 选中即写入 `gymlog.theme` 并重绘；不打断进行中的训练会话。
- 另一会话改首页时须保留该块（见 `docs/SESSION-COORDINATION.md`）。

## 6. 资源与文件

| 路径 | 说明 |
|------|------|
| `docs/theme-preview.html` | 预览稿（已确认） |
| `docs/theme-assets/*.jpg` | 主题专用图；实现时复制到 `www/theme-assets/`（或 `www/img/themes/`）随包发布 |
| `www/app.css` | 四套 CSS 变量 + 背景/卡片/按钮样式；主改文件 |
| `www/app.js` | 仅：主题读写、首页芯片、`boot` 应用主题、i18n 文案 |

配图规则：某主题屏幕内只引用该主题前缀文件，禁止跨套复用。

## 7. 与正式 App 的映射

预览里的布局是示意。正式 App 保持现有页面结构（首页 / 选动作 / 训练中 / 历史 / 模板），用主题变量换：

- 背景（可含背景图或渐变遮罩）
- 卡片、列表按钮、主按钮、ghost、危险色
- 休息条、chip 选中态
- 可选：训练列表项旁显示对应主题风格的缩略图（若动作库已有 gif/图则优先用现有；主题图仅作氛围，不伪造动作库）

首版最低要求：颜色 + 背景氛围图 + 圆角/边框气质到位；动作行旁主题缩略图可为后续小迭代。

## 8. 协作边界

见 `docs/SESSION-COORDINATION.md`。功能会话不重做配色；本会话不改备份/震动/进步逻辑。

## 9. 验收

1. 四套芯片可切换，刷新后仍是上次选择。
2. 四套视觉与预览气质一致，且图片不跨套复用。
3. 开始训练、记组、休息、历史、模板仍可用。
4. 离线可用；主题资源打进包内，不依赖外网。
